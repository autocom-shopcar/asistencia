# Asistencia

Kiosco de checadas para una tablet fija por localidad: reconocimiento facial con prueba de vida (parpadeo o giro de cabeza), cola sin red y envío a Shop Car. Se vincula con un código que se genera en Shop Car → Recursos Humanos → Asistencia → Tablets.

Reconocimiento facial: [@vladmandic/face-api](https://github.com/vladmandic/face-api) 1.7.15 (licencia MIT, en `lib/LICENSE`).
